# Os três aplicativos do Mototáxi

Cada tela é um aplicativo separado, com nome, ícone e tela inicial próprios:

| Aplicativo | Ícone | Endereço | Para quem |
|---|---|---|---|
| Mototáxi | amarelo | `https://SEU-ENDERECO/` | passageiros |
| Mototáxi Motoqueiro | preto | `https://SEU-ENDERECO/motoqueiro/` | motoristas |
| Mototáxi Central | azul | `https://SEU-ENDERECO/central/` | central e atendentes |

## Instalar (sem loja)

**Android (Chrome):** abra o endereço → três pontinhos → **Instalar aplicativo**.
Dentro do próprio aplicativo também existe o item **Instalar aplicativo** no menu.

**iPhone (Safari):** abra o endereço → botão **Compartilhar** → **Adicionar à Tela de Início** → **Adicionar**.

**Computador (Chrome ou Edge):** ícone de instalar na barra de endereço. Ideal para a central.

Requisito: o endereço precisa ser HTTPS (com cadeado). Em `localhost` só instala no próprio computador.

## Avisos

Depois de instalar, toque no menu → **Ativar avisos**. Assim o passageiro é avisado quando o motorista chega, mesmo com o app fechado.
